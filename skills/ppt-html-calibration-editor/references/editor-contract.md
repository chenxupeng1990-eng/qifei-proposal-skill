# PPT HTML 浏览器校稿编辑器设计规范

日期：2026-07-20  
状态：设计已确认，等待书面规范复核  
范围：B——文字编辑 + 图片替换、移动与缩放

## 1. 目标

把当前用于生成 16:9 PPT PNG 的 HTML 页面增加一个轻量校稿层，让用户可以在浏览器中直接调整文字和指定图片，同时不破坏原有页面结构、设计语言和自动截图流程。

编辑器服务于“快速校稿与回写”，不是通用设计软件，也不替代 Figma、Canva 或 PowerPoint。

## 2. 使用方式

- 普通预览：直接打开页面，不加载编辑工具。
- 单页编辑：`?edit=1&capture=slide52`。
- 单页截图：`?capture=slide52`，编辑 UI 必须完全隐藏。
- 恢复默认：清除当前页浏览器暂存，重新载入源 HTML 状态。

## 3. 可编辑范围

### 3.1 文字

通过 `data-editable="text"` 明确开放：

- 单击选中，双击进入文字编辑。
- 修改正文内容。
- 调整字号、字重、行距、颜色、水平对齐。
- 拖动文字框位置。
- 拖动控制点改变文字框宽高。

不开放复杂富文本、逐字样式、文字绕排、旋转和字体上传。

### 3.2 图片

通过 `data-editable="image"` 明确开放：

- 拖动位置。
- 等比例缩放。
- 调整透明度。
- 调整前移／后移层级。
- 用本地图片替换当前图片；替换仅在浏览器会话中生成对象 URL，并在导出时提示需要同步保存原始图片文件。

背景、装饰纹理、固定品牌边栏默认锁定。产品图、人物图和核心视觉载体由页面配置决定是否开放。

## 4. 交互结构

### 4.1 顶部工具栏

始终固定在画布外层，不参与 1920×1080 截图：

- 当前页名称。
- 编辑／预览切换。
- 撤销、重做。
- 保存状态提示。
- 导出 JSON。
- 导入 JSON。
- 恢复当前页。

### 4.2 浮动属性面板

选中文字时显示：字号、字重、行距、颜色、对齐。  
选中图片时显示：透明度、层级、替换图片、恢复比例。

### 4.3 画布反馈

- 蓝色选中框与八个缩放控制点。
- 拖动时显示中心线、边缘线和安全区参考线。
- 坐标吸附阈值为 6 px，可临时按住修饰键取消吸附。
- 编辑器不改变原页面的 1920×1080 逻辑坐标；浏览器缩放只影响显示比例。

## 5. 数据模型

每个可编辑元素必须拥有稳定的 `data-edit-id`。状态按页面 ID 隔离：

```json
{
  "schemaVersion": 1,
  "documentId": "client-proposal",
  "slideId": "slide52",
  "updatedAt": "2026-07-20T00:00:00.000Z",
  "elements": {
    "slide52.title": {
      "type": "text",
      "text": "日常经营中，内容节点与销售节点承担不同任务",
      "x": 72,
      "y": 80,
      "width": 920,
      "height": 124,
      "fontSize": 52,
      "fontWeight": 700,
      "lineHeight": 1.12,
      "color": "#062957",
      "textAlign": "left",
      "zIndex": 20
    }
  }
}
```

浏览器暂存键：`ppt-editor:<documentId>:<slideId>:v1`。

## 6. 保存与回写流程

1. 编辑动作发生后 300 ms 防抖写入 `localStorage`。
2. 页面显示“已保存到本机浏览器”，避免误认为已改写源文件。
3. 导出 JSON 时包含页面 ID、元素状态和被替换图片的原始文件名。
4. Codex 读取 JSON，把坐标和样式变化回写至 HTML/CSS，并处理替换图片文件。
5. 重新运行原截图脚本，输出正式 PNG。

首版不让浏览器直接写入源文件，因为 Codex 预览环境、iframe 和不同浏览器对 File System Access API 的支持不稳定。

## 7. 模块边界

- `ppt-editor.js`：编辑状态、选择、拖拽、缩放、撤销重做、导入导出。
- `ppt-editor.css`：工具栏、属性面板、选中框、参考线、安全区。
- `ppt-editor-config.js`：文档 ID、页面 ID、可编辑元素、锁定规则。
- 页面 HTML：只添加 `data-editable` 与 `data-edit-id`，不嵌入编辑器业务逻辑。

该结构保证编辑器可以复用于不同章节的 HTML 页面。

## 8. 错误与保护

- 缺少 `data-edit-id` 的元素不进入编辑状态。
- 导入 JSON 时校验 `schemaVersion`、`documentId`、`slideId`。
- 图片替换失败时保留原图，不写入错误状态。
- 文本框超出画布时给出红色警示；允许继续编辑，但导出前提示。
- 截图模式检测到编辑 UI 时直接报错，防止工具栏进入 PNG。
- “恢复当前页”需要二次确认，只删除当前页的本地暂存。

## 9. 验收标准

- 在 Chrome、Edge、Safari 当前稳定版中可以进入编辑模式。
- 标题和正文可直接修改并在刷新后恢复。
- 指定图片可替换、移动、等比例缩放。
- 拖动与缩放坐标以 1920×1080 为基准，不受浏览器窗口尺寸影响。
- JSON 可以导出、重新导入，并恢复相同画面状态。
- `?capture=<slideId>` 输出与未接入编辑器前一致，不包含任何编辑 UI。
- 页面中被锁定的背景和装饰层无法误选。

## 10. 首次接入范围

先在一个独立演示页验证完整交互，再接入现存章节页面。优先接入标题、正文、产品图和核心场景图；背景纹理、章节边栏与页脚固定标识继续锁定。

当前工作区仍保留第一至第四章的部分 HTML 源文件；后续缺失页面恢复后使用相同模块接入，不为单页重复开发编辑逻辑。
