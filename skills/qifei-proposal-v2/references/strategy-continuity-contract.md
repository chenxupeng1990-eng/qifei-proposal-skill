# 提案策略连续性合同

## 1. 目的

提案不是若干专业板块的集合，而是一条推动客户作出决定的连续论证。

行业、人群、产品、内容、直播、投放、运营和团队只是可调用的论证材料。不得因为标书按模块提问，就把提案写成相互独立的模块回答。每个章节、每一页和每个标题都必须服务同一个核心策略，并让下一步成为前一步推导出的必要结果。

## 2. 三层策略树

目录生成前必须建立三层策略树：

### 2.1 总策略

写成完整的因果判断：

```text
因为【关键事实与核心矛盾】，
所以品牌必须【策略选择】，
通过【核心方法】，
最终实现【客户目标决策或业务结果】。
```

### 2.2 章节命题

每章必须填写：

- `strategy_question`：总策略推进到这里，必须回答什么问题；
- `chapter_claim`：本章要证明的唯一命题；
- `strategy_input`：本章继承上一章的哪个已成立结论；
- `reasoning_step`：本章完成哪一步推导；
- `chapter_proof`：用什么证据、内容原型或工作件使命题成立；
- `strategy_output`：本章结束后新增了什么已成立结论；
- `next_chapter_necessity`：为什么该结论必然要求下一章出现；
- `emotional_shift`：观众在本章前后发生什么情绪变化。

章节名称不能只是“行业分析、关键人群、短视频、直播、运营”等模块标签。它需要表达本章在总策略中的动作或结论。

### 2.3 页面论证

每页必须属于本章论证链中的一个必要步骤：

```text
前提 / 问题
→ 证据 / 洞察
→ 判断
→ 策略选择
→ 执行证明
→ 行动 / 下一层问题
```

不是每章都机械使用六页，但页面顺序必须能够映射到这条推导。无法说明本页在论证链中承担哪一步，该页应删除、合并或换序。

## 3. 章节接口

相邻章节之间必须存在明确接口：

```text
上一章 strategy_output
= 下一章 strategy_input
```

章节转场需要回答：

1. 上一章已经证明了什么；
2. 这个结论为什么还不足以完成总策略；
3. 下一章必须解决什么新的决策问题。

仅使用“接下来进入内容规划”“下面看直播间”“最后是运营保障”等栏目式转场，视为接口失败。

## 4. 标题链验收

目录确认、章节确认和全案冻结前，分别执行一次“只读标题”测试：

1. 隐藏正文，只按顺序朗读章节标题和页面标题；
2. 每个标题都应提供新前提、新判断、新选择、新证明或新行动；
3. 相邻标题之间可以自然补出“因此、但是、所以、为了证明、由此进入”等真实逻辑；
4. 任意交换两页或两章的顺序，应明显破坏论证；若不影响理解，说明它们只是并列模块；
5. 只读标题后，应能复述总策略如何一步步成立。

以下标题链不通过：

- 多个“XX分析／XX策略／XX规划／XX保障”并列；
- 每章重新从背景讲起；
- 标题分别正确，但互相没有前提与结论关系；
- 多页反复解释核心口号，却没有推进到选择、动作和验证；
- 标题依赖正文补充才能看出与总策略有关。

## 5. 策略回扣规则

“贯穿策略”不等于每页重复核心口号。每次回扣必须完成一种新转化：

- 行业事实 → 品牌机会；
- 品牌机会 → 产品角色；
- 产品角色 → 消费者选择理由；
- 选择理由 → 内容表达；
- 内容表达 → 现场成交；
- 成交信号 → 经营放大；
- 经营系统 → 客户最终决策。

若策略主张只作为页眉、章节口号或装饰性重复出现，没有改变本页判断或动作，视为没有贯穿。

## 6. 生成顺序

禁止按章节名称并行独立写稿后再拼接。必须按以下顺序：

1. 确认总策略因果句；
2. 生成章节策略接口表；
3. 只生成章节标题链并完成朗读；
4. 为每章生成页面论证链；
5. 只生成全案页面标题链并完成朗读；
6. 章节骨架确认后，一次性填入本章全部页面的证据、上屏文案、演讲任务与视觉意图，不生成完整讲稿；
7. 整章写入飞书并连续阅读，再逐页评论和确认；
8. 每完成一章，连同上一章结尾和下一章开头一起复核。

逐页确认是审批粒度，不是默认生成粒度。不得为每一页单独启动一次内容生成，也不得在没有确认章节骨架前一次生成整章正文。

完整讲稿等待全部PPT页面、拆页和最终页序确认后，再以最终PPT为唯一输入一次性生成。讲稿不得反向决定或提前固化策略与页面结构。

任何单章修改改变 `strategy_output` 时，下一章的 `strategy_input` 和所有相关标题必须标记过期并重新检查。

## 7. 放行门禁

以下任一情况成立，不得确认目录、章节或内容冻结：

- 章节可以任意调换顺序；
- 某章独立成立，但无法说明它如何推进总策略；
- 上一章输出与下一章输入不一致；
- 章节内页面是并列知识点，没有论证先后；
- 只读标题无法复述策略推导；
- 标题链靠栏目名连接，缺少真实因果；
- 核心策略只被重复，没有被转化为后续动作；
- 标书要求被逐项回答，却没有被编入同一套品牌解法。

放行必须同时满足：

1. 总策略因果句清晰；
2. 章节策略接口闭合；
3. 章节内页面论证链成立；
4. 标题链可独立复述；
5. 情绪曲线与策略推进同向；
6. 每个执行章节都能回溯到最初的品牌判断。

## 8. 对抗检测问题

对抗检测必须直接回答：

- 如果删除章节名，本章仍能看出服务哪条总策略吗；
- 本章新增了什么不可被其他章节替代的策略结论；
- 本章结论是否真实成为下一章的前提；
- 任意换序后，论证是否仍成立；
- 页面标题是在推进观点，还是只在标记内容类别；
- 标书模块是否被重新组织成品牌解法，而非逐条作答；
- 视觉变化是否跟随策略阶段变化，还是把板块割裂得更严重。
