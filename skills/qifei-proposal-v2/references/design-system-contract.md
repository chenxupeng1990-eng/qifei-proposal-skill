# DESIGN.md与设计令牌合同

设计校准通过后，将确认结果编译为 `DESIGN.md` 和 `deck/design-tokens.json`。

## 必须固定

- 品牌来源ID、Logo规则和安全区；
- 色彩职责、字体、字号与间距尺度；
- 图形母题、材质、光向、镜头和产品融合方式；
- 网格、安全区、组件语法与最小可读标准；
- 首页、目录、章节页、内容页和结尾页系统；
- 统一 `visual_family_id`；
- Image2使用范围、提示词去标识化和资产审批规则；
- 页面路线：全部正式页为“整页 Image2 设计底图＋HTML 文字层”，写明各类页面底图的构图、文字区和明暗规则；不得为任何页面类型开纯 HTML 或配图框例外（单页例外只能由 Owner 逐页批准）；
- 母版清单：每类页面（封面、目录、章节、数据、产品、流程、内容样张、结尾等）对应哪张已确认的校准页，正式页底图以它为 Image2 参考图生成；
- 透明PNG槽位、Alpha、锚点、边界与禁止遮挡区；
- 低／中／高密度预算和必须拆页的条件。

## 必须保留弹性

- 正文页列数与媒体比例；
- 模块组合、留白和强调方式；
- 章节属性对应的摄影、材质和构图变量；
- 内容关系决定的图表、流程、场景、工作件和Demo载体。

一致性不等于重复同一版式。所有变化必须仍可回溯到同一视觉家族和版式语法。

## 版本规则

- `DESIGN.md` 与 `design-tokens.json` 使用同一个 `design_version`；
- 公共令牌或组件改变时，全部下游页面过期；
- 单页内容修改只重建受影响页及必要转场；
- 正式页面资产必须引用当前设计版本和视觉家族。
