# 数据到策略证据引擎

## 1. 定位

提案中的数据分析首先服务策略，不以客观、完整、面面俱到的行业报告为目标。

它承担两个任务：

1. **策略已经形成时，用数据寻找证据**：证明品牌的判断正确、机会真实存在、选择的路径值得执行。
2. **策略尚未形成时，从数据中推导策略**：发现增长不对称、竞争空位、品牌优势或经营矛盾，形成对品牌有利且能够落地的策略。

数据必须推动提案前进。只有数据、没有判断，不构成提案分析；只有判断、没有证据，不构成可信策略。

## 2. 两种工作模式

### 模式 A｜策略求证

适用于客户目标、品牌方向或核心策略已经较明确的项目。

工作链：

> 已有策略假设 → 明确需要证明的关键命题 → 定向寻找数据 → 组合证据 → 强化策略正当性 → 导向执行方案

数据选择围绕以下问题：

- 为什么现在做是正确的；
- 为什么选择这个平台、品类、人群、价格带或经营模式；
- 为什么该策略比其他选择更有增长潜力；
- 哪些历史结果或市场表现证明它可以被复制、放大。

典型的策略求证案例是地域门店 O2O 项目：地域门店直播与线上线下互哺的模型已经成立，区域人群占比、门店活动结果、矩阵规模和年度增长数据共同证明该模式值得全国复制；数据中台与内容生产系统则证明复制能够被管理。

### 模式 B｜数据生策

适用于品牌目标宽泛、策略尚未收敛或需要服务商提出突破路径的项目。

工作链：

> 数据扫描 → 识别不对称关系 → 解释其商业含义 → 找到品牌可占据的位置 → 提出策略选择 → 推导人群、货品、内容与经营动作

重点寻找六类不对称：

1. 市场在增长，品牌未同步增长；
2. 品牌曝光不足，但点击或成交效率较高；
3. 大盘已成熟，细分类目或价格带仍有空位；
4. 品牌已有核心人群，但增量人群出现断层；
5. 竞品依靠某种经营组合增长，品牌尚未建立；
6. 消费需求存在，但平台供给或内容表达不足。

典型的数据生策案例是运动鞋服品牌反攻项目：行业大盘增长与品牌生意下滑形成矛盾；低曝光下仍有较高点击转化，说明问题更接近声量和触达规模，而非产品完全失去吸引力；人群、品类、价格带和竞品经营数据进一步推导出“巩固高质量基本盘、补年轻增量、恢复核心品类、布局竞争空位、建立自营与达人双轮”的策略路径。

另一类高端运动品牌项目同时使用两种模式：大盘增速、类目集中度与高价格带供给不足，推导出高端细分类目进入内容电商平台的机会；历史购买标签、平台人群 TGI 和内容偏好，再为核心人群切入与由近到远破圈提供证据。

## 3. 数据推导的最小单元

每组数据必须形成以下五段：

1. **数据事实**：发生了什么；
2. **关系判断**：与大盘、竞品、历史、人群或供给相比，哪里出现不对称；
3. **品牌含义**：这对客户意味着什么；
4. **策略选择**：因此应该占据什么位置、优先做什么；
5. **执行接口**：该结论如何改变人群、货品、内容、直播、投放或节奏。

标准表达：

> 数据显示 A；与 B 相比，真正值得关注的是 C；这说明品牌已经具备／尚未占据 D；因此本案选择 E，并在后续通过 F 落地。

不得在展示数据后直接跳到执行清单，也不得用“市场潜力巨大”“建议持续关注”结束。

## 4. 数据选择原则

- **先有决策问题，再找数据**。不做无目的的数据堆积。
- **优先寻找关系，不迷信单个大数字**。增速与规模、曝光与转化、份额与效率、核心与增量的组合更容易产生策略。
- **数据为品牌建立信心**。行业信息用于证明品牌选择顺势、产品进入有理、服务路径有机会。
- **判断必须有态度**。允许从同一组事实中选择最能支持本案的解释，但不得篡改数据或虚构因果。
- **负向数据必须转化为机会结构**。指出问题之后，必须说明品牌仍拥有什么以及如何反攻。
- **每页只服务一个策略判断**。图表、数字和结论共同指向同一件事。

## 5. 从数据到全案策略

数据分析完成后，至少产出：

- 三至五条有证据的行业／品牌判断；
- 一个最关键的增长矛盾；
- 一个品牌可占据的策略位置；
- 一条从数据结论通往人群、货品、内容与经营的策略链；
- 每个后续章节所继承的数据结论。

示例接口：

| 数据结论 | 策略输出 | 后续章节输入 |
|---|---|---|
| 高价格带需求存在但供给不足 | 抢占高端品类定义权 | 产品价值与价格理由 |
| 品牌低曝光但高转化 | 优先放大高质量人群池 | 内容触达与流量放大 |
| 核心用户稳定但年轻人断层 | 基本盘巩固＋增量破圈 | 两类人群与内容矩阵 |
| 地域门店模型已跑通 | 将单店能力复制为区域矩阵 | O2O组织、系统与排期 |

## 6. 提案中的页面结构

数据章节不是独立研究报告，建议按以下情绪和逻辑推进：

1. 用大盘或用户变化确认品牌方向；
2. 用差异数据制造关键矛盾；
3. 用品牌自身数据发现可利用的优势；
4. 用竞品、品类或价格带数据找到空位；
5. 收束为明确策略，而非中立结论；
6. 将策略依次交给人群、货品、内容与经营章节。

每一页标题应直接表达策略判断，不能只写“行业规模”“人群画像”“竞品分析”。

## 7. 与运营数据回环的边界

策略数据回答：

> 为什么采取这套策略，以及品牌凭什么有机会赢。

运营数据回环回答：

> 执行后发生了什么，下一轮如何调整。

二者都可以出现在提案中，但必须分开：

- 前者位于策略推导阶段，决定全案方向；
- 后者位于运营能力阶段，证明策略能够持续学习和放大。

不得用日周月复盘、驾驶舱或异常诊断替代前期策略数据分析。
