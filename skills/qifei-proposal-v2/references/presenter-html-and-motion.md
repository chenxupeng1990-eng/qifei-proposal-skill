# HTML 讲解台与分层沉浸式动效规范

本文件是 `qifei-proposal-v2` 在阶段 08 导出分支的可选增强规范。它只在**全部正式页面定稿、终版讲稿生成、低级错误核对通过**，且 **Owner 明确选择 HTML 作为最终交付讲解台版本**时加载；不得在前 01–07 阶段预读或反向干扰内容与视觉定稿。

---

## 1. 适用边界与交付形态

1. **前置门禁**：
   - 全部正式页面 PNG 已由 Owner 确认并锁定最终页序；
   - 终版讲稿已按最终页序完成并核对一致；
   - `final_check.py` 通过（无错别字、无孤字溢出、无页序漂移）。
2. **不篡改内容红线**：
   - 动效与讲解台外壳属于「讲解增强层」，**绝不修改**已冻结的上屏文字、数据口径、图表比例、产品包装与品牌 Logo。
   - 若因动效需要单独叠加矢量文字层（如 Hero / Ending 视频页），文字内容、换行与字号必须与定稿页像素级一致。
3. **交付物规格（`scripts/build_presenter_html.py`）**：
   - 默认交付**单文件 100% 离线 HTML**（页面转高质 WebP 内嵌，视频按需内嵌），双击即可在浏览器演示，零外链、零本地服务器依赖。
   - 软体积预警：单文件超过 **60 MB** 时提示 Owner 选择「压缩视频码率」或切换为「`HTML + 同级 media/` 离线文件夹」，不以牺牲讲解效果强砍动效。

## 2. HTML 讲解台核心功能标准

通过 `scripts/build_presenter_html.py` 打包生成的讲解台统一具备以下能力：

| 能力模块 | 可选开关 | 默认标准行为 |
|---|---|---|
| **语言模式** | `--langs zh` / `en` / `zh,en` | 单语时隐藏语言切换器；中英双语时顶栏与快捷键 `L` 同步切换页面画面、目录标题与动效叠加文案 |
| **演讲讲稿** | `--editable-notes`（默认开启） | 右侧可折叠讲稿抽屉（`N`），支持单语 / 中英双语对照视图；开启编辑时（`E`）支持在线改稿、`localStorage` 自动保存、一键「存为新 HTML / 导出 MD / JSON 导入导出 / 单页还原」 |
| **双屏投屏演示** | 默认内置 | 顶栏「双屏演示」按钮，面向外接投影/大屏扩展显示器场景（详见第 3 节） |
| **沉浸动效开关** | `--motion-bundle <dir>` | 顶栏全局「沉浸动效: 开/关」（`V` 键）——演讲现场遇设备卡顿或需静版展示时，一键切回 100% 静态高定稿；每页提供重播（`R`） |
| **全屏与防困死** | 默认内置 | `F` 键进入全屏演示；全屏态顶栏右侧常驻「退出全屏 · 看讲稿」按钮，确保随时退回讲稿视图 |

## 3. 双屏投屏演讲者模式（Audience + Presenter Console）

解决真实比稿现场「大屏放全屏画面与动效、讲者电脑看讲稿」的核心痛点，**纯单文件 `file://` 双击即用**：

1. **连接机制**：
   - 主窗口点击「双屏演示」通过 `window.open()` 创建同源空白「观众大屏窗口」，由主窗口直接注入渲染舞台并建立内存直连 + `postMessage` 双通道同步，完全避开 `file://` 跨域限制。
2. **外接大屏（观众窗口）**：
   - 仅显示 16:9 纯净画面 + 完整动效层（视频、Canvas、3D、互动窗等），无目录、无讲稿、无多余控件；
   - `.slide-frame` 必须使用数学锁比 `width: min(100vw, calc(100vh * 16 / 9)); height: min(100vh, calc(100vw * 9 / 16));`（严禁仅写 `width: 100vw; max-height: 100vh;`），防止非全屏窗口下顶部地址栏挤压高度导致底图与动效层视差错位或底部裁切；
   - 讲者将窗口拖至外接大屏后点击全屏（或按 `F`），同时解锁浏览器有声媒体自动播放权限。
3. **讲者电脑（控制台视图）**：
   - 自动切为三区布局：**当前大屏画面同步预览 + 下一页预告 + 演讲总计时器 / 本页建议时长提示 + 超大字号高可读讲稿**；
   - 完整支持无线翻页笔（`← / → / PageUp / PageDown / Space`）；
   - **跨屏手势滚讲稿**：在演讲者主窗（左侧画框/遥控条/顶栏）、外接大屏窗口以及内嵌短片 `iframe` 内均捕获垂直触控/滚轮手势并实时转发滚动讲稿区（`notesWheel`），讲者无需把鼠标来回移回讲稿栏即可顺畅滑读，同时保留目录栏与文本框原生滚动；
   - **互动弹窗直投遥控**：对包含视频、3D 沙盘或内嵌短片的交互页，在演讲者预览画框上直接提供大屏遥控条（并拦截本机点击自动转发至大屏开启、切视角/声音/重播/退出），实时回显大屏播放状态；
   - 支持从讲者端毫秒级远程同步大屏：**翻页、切换中/英（`L`）、重播大屏动效（`R`）、全局开关动效（`V`）、远程触发/退出当前页交互窗（如直播间/3D 沙盘/收官短片）、一键黑屏/恢复（`B`）**。

## 4. 动效分层实现框架

开工前必须先从项目 `DESIGN.md` / `design-tokens.json` 提炼唯一 **「品牌视觉母题（Motion Motif）」**（例如澳洲植物品牌用植物藤蔓与午后光影，医美/科研品牌用洁净光束与水波折射，奢品/香氛品牌用暖金微光与丝带质感），禁止把同一套视觉元素跨品牌硬套。

### 4.1 基础配置（选择 HTML 讲解台即默认配备）

| 页面类型 | 动效定位 | 标准实现方式 | 边界与降级 |
|---|---|---|---|
| **Hero 封面页** | 品牌气质开场定调 | 6–8s 固定机位品牌氛围视频铺底 + 上层独立 1920×1080 矢量标题与 Logo 渐入 | 视频内产品与包装必须锁定原图不变形；文字永不烧录进视频，确保双语清晰。无视频能力时降级为局部母题 Canvas 微动 |
| **Ending 致谢页** | 与 Hero 首尾呼应的收尾仪式感 | 6–8s 固定机位收尾视频（如礼赠封箱/光影定格）+ 独立矢量致谢层，播完稳稳定格终帧 | 同上；无视频能力时降级为轻光影收束动效 |
| **章节过渡 / 目录页** | 强化章节结构感与推进节奏 | 当前章节行柔和扫光 + 贴外缘品牌母题微环绕（如藤蔓书签、细线光迹） | 严禁压盖任何目录文字；双语模式下按中英文实际文字宽度分别对齐 |
| **页间切换动效** | 柔化翻页顿挫 | 同章内轻淡入（`200–260ms`）；跨章略加深呼吸过渡（`300–340ms`） | 禁止旋转、飞入、弹跳、百叶窗等廉价 PPT 转场，不阻断连续快速翻页 |

### 4.2 增强配置（按母稿情绪曲线匹配，优先服务讲解需求）

**不设死板的增强页总比例上限**，按母稿章节「情绪方向」与单页 `emotional_target` / 页面角色精准分三档配置：

| 档位 | 适用页面特征（母稿映射） | 动效职责 | 典型做法 | 禁止事项 |
|---|---|---|---|---|
| **A 档｜情绪克制 / 结构陈述页** | 情绪平稳的多栏对比、全年排期、四步流程、方法论页 | 缓解多栏与密集文本的阅读枯燥感，理顺横向/纵向推进关系 | 用低对比品牌母题/细线沿列缝或图文分界带有机串联，落定后轻呼吸，可选轻点击微反馈 | 不遮挡标题与正文；不做大面积高对比色块闪烁 |
| **B 档｜强逻辑商业数据页** | 市场规模、价盘结构、渠道格局、利润测算、多年度增长目标曲线 | **注意力引导与结论锚定**，帮讲者把评审视线锁到关键数字与拐点 | 渐进式曲线爬坡描画、关键峰值/拐点四芒星标与里程碑浮标、核心对比列或差额区渐显高亮 | **严禁夸张特效**；不篡改坐标与数值比例；所有标注必须取自页面源码精确坐标 |
| **C 档｜情绪高点 / Marketing 故事线页** | 母稿标明「张力峰值 / 记忆锚点」的营销、场景共鸣、直播/种草 Demo、线下空间页 | 把静态概念变成可感现场，替讲者省去大段口头想象成本 | ① 局部实景微动框（5–6s 人物/氛围循环）<br>② 实景前后景抠图遮挡交互<br>③ 沉浸穿越演示窗（如点击手机进带原声/弹幕直播现场）<br>④ 离线 3D 体验沙盘（Three.js 可拖拽旋转与切视角）<br>⑤ 多场景差异化氛围逐格点亮 | 每页必须说清服务的具体讲解节拍；若无明确故事线支撑，直接降回 A 档或静态 |

### 4.3 连续讲解防枯燥规则（Pacing Guardrail）

在输出《动效配置单》前，必须按最终页序扫描整套提案的动效间隔分布：

- **12–19 页连续无动效**：在配置单中标出提醒，请 Owner 判断是否需要提神点；
- **≥ 20 页连续无动效**：**触发强制补位建议**——必须在该静默区间中段按页面性质穿插 1–2 个低干扰动效（纯数据段补 B 档注意力标注，策略/分栏段补 A 档轻关系串联），确保整场演讲节奏有呼吸、不失焦。

## 5. 动效美感与防低能力模型翻车 6 条硬约束

以下约束用于防止不同能力层级的模型产出廉价、土气或破坏排版的特效：

1. **色盘锁死设计系统**：所有线条、光晕、星标、粒子与浮标必须取自项目 `design-tokens.json`（品牌主色 + 克制中性色/微暖金），严禁引入高饱和荧光色、彩虹渐变、赛博霓虹或厚重黑色阴影。
2. **运动物理克制**：禁止匀速机械位移、剧烈弹跳（bounce）、抖动（shake）、旋转飞入与 3D 翻牌。统一使用柔顺缓出曲线（如 `cubic-bezier(.22, 1, .36, 1)`），入场时长控制在 `0.4–2.8s`，落定后仅允许极微幅呼吸（幅度 `≤ 2–4px`），不持续高频闪烁。
3. **单页唯一视觉焦点**：一页最多承载一个主导动效叙事，禁止上下左右多个区域同时乱动分散注意力。
4. **模板优先 · 宁简勿丑（防低能力模型翻车）**：
   - 禁止模型凭空手写复杂具象人物/产品/建筑的 Canvas 或 SVG 插画去冒充高定；
   - 真实人物、产品与空间类画面（Hero、Ending、C 档实景）必须走「定稿原图首帧（或首尾帧双锚）+ AI 视频 + 亚像素稳像 + 产品包装与文字安全区锁底」；若当前环境无可靠视频能力，直接降级为局部静奢微光或保持静态高定，绝不硬凑低质动画；
   - A/B 档优先采用参数化标准动效模式（细线串联、源码坐标曲线爬坡、精准星标、卡片流光边框），确保下限稳定。
5. **终帧可打印美学**：任何动效播完停住的最终画面，本身必须构图完整、零遮挡、零文字溢出，可直接截图用于 PDF 存档。
6. **零幽灵遮挡与零视差工程红线**：
   - 观众窗口 `.slide-frame` 强制数学锁定 16:9，所有动效舞台统一按内框精确比例缩放（`scale(layer.clientWidth / 1920, layer.clientHeight / 1080)`），避免 1px 边框或非 16:9 窗口造成的像素偏移；
   - 所有非激活层与未打开弹窗强制 `visibility: hidden` + `:not(.open) * { pointer-events: none !important; }`，且**禁止对 `visibility` 添加 CSS transition**，彻底杜绝跨页透明层拦截点击或切页残影。

## 6. 执行工作流与验收门禁

1. **第一步｜生成《动效配置单》并报 Owner 批准（先定盘、再开工）**：
   - 动笔前先读 [motion-worked-example.md](motion-worked-example.md)：一份真实提案里 Owner 怎么判断每页动不动、为什么改。学判断，不照抄做法；
   - 读取定稿母稿（章节情绪方向 + 单页 `emotional_target`）与最终页序，输出 `exports/motion-plan.json` 与可读清单，逐页列明：`slide_id`、档位（`basic / A / B / C`）、服务节拍、实现方式、是否需外部视频生成（预估点数/耗时）、以及**最大连续静页跨度检查结果**。
   - **未获 Owner 批准配置单，不得启动视频生成或大面积编写动效代码。**
2. **第二步｜分轨制作与单页样张校准**：
   - 视频类资产（Hero / Ending / C 档实景）必须抽 12 帧联络表肉眼核对：人物自然度、机位稳定性、产品包装字标零错字零变形，必要时做 OpenCV 亚像素稳像与文字安全区锁底；
   - 轻前端类动效先做 1 页品牌母题样张确认审美基调，再批量铺开。
3. **第三步｜一键构建离线讲解台**：
   - 运行 `python3 scripts/build_presenter_html.py` 打包输出 `exports/<项目名>_Presenter_Offline.html`。
4. **第四步｜真实浏览器实机验收（缺一不可）**：
   - 逐类抽检渲染截图（若双语则中/英双版均查）：确认零文字遮挡、零徽标溢出、坐标对齐；
   - 交互弹窗/按钮逐一做 `elementFromPoint` 命中测试与真实点击测试（静音、重播、退出、关闭 3D 等 100% 响应）；
   - 跨页检查：离开动效页后相邻静态页零残留、零鼠标拦截；
   - 双屏演示联调：打开「双屏演示」，验证讲者端翻页、切语言、重播、黑屏与大屏窗口同步；
   - 兜底测试：点击「沉浸动效: 关」后全案 100% 退回纯净静态稿。
