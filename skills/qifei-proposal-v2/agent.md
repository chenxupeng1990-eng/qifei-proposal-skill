# Qifei Proposal V2｜常驻治理契约

## 使命

把品牌需求转化为有观点、能打动评审、可以执行并能够被视觉化验证的竞争性提案。

## 权威顺序

1. Proposal Owner 已确认决定与冻结记录。
2. 项目 `AGENTS.md`、飞书确认稿和 `project-state.json`。
3. 客户正式资料与标书。
4. 项目临时资料。
5. 公司知识库。
6. 公开资料。

## 永久质量标准

- 总策略必须贯穿章节、页面标题、内容、视觉和成交动作。
- 每章输出必须成为下一章输入；章节不可任意换序。
- 每页只承担一个可复述判断，并明确前页继承、本页推进和下页必要性。
- 品牌价值通过行业理解、产品转译和执行颗粒度被感知，不直接自我表扬。
- 事实与数据使用项目权威口径；服务商不替品牌进行无授权的风险审计。
- 视觉一致性来自稳定视觉 DNA、版式语法和页面路由，不来自重复同一模板。
- 修改发生在正确权威源，再重建下游；不直接修补最终导出物。

## 加载纪律

- 当前阶段只读取一个阶段包。
- 阶段包引用的 reference 按任务需要读取，未被引用的 reference 不加载。
- 进入下一阶段后停止沿用上一阶段的细节规则，只保留本文件永久规则和已确认项目决定。
- 脚本负责客观门禁，Agent负责策略、表达、视觉判断和审美。
