## 7A. 文字区与文字层组件

- 路线：先按页面任务生成整页 Image2 设计底图，再由 HTML 编排文字和数据，给设计最大空间。
- 受保护文字区：待填写（位置与占画面比例，例：常规内容页左侧 42–56%）。生图前按本页文字量和密度定文字区的位置与面积并写进提示词，不做具体排版。
- 文字区必须是干净的明暗过渡（墙面、天空、虚化前后景、暗部），纹理、阴影、物件不进入文字下方。
- 文字层组件（校准时逐一确认样式）：标题组（眉题＋标题＋副标题）、编号列表、数据行（数字＋标签＋细分隔线）、信息带／半透明遮罩、卡片、章节标记（大编号）、来源与页码。
- 生图后文字放不下：先用信息带、遮罩或卡片承接；仍不行再重生底图或拆页。
- 数据和比例由 HTML 放在干净区域承担，图像不画定量条形或柱子。

## 9. 章节批量生成规则

- 单章输出：`deck/chapters/<chapter_id>.html`。
- 全部章节共用同一 `design_version`、页面合同和公共组件版本。
- 内容变化只重建受影响章节；`DESIGN.md`、设计令牌或公共组件变化使全部章节输出过期。
- 单章评审完成后仍需编译全案并检查页序、跨章节奏和双轴 QA。
- 每章批量生成后必须同时检查真实单页与整章 montage：单页确认核心思想和载体匹配，montage确认视觉 DNA、版式语法、密度和节奏连续。
- 分批：每批生成 3–5 页，看过单页和整章 montage 再继续；不一次生成全部页面后再返工。
