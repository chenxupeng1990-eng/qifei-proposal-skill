# 提案立场与说服力门禁

## 核心原则

提案的第一目标是推动客户相信、期待并选择方案。事实准确是表达边界，不是叙事目标。

> 事实负责守住边界，策略负责作出判断，创意负责让判断被相信。

对品牌提供的产品、业务与案例信息，按项目已核准口径主动表达。来源、版本、假设、风险和信息缺口保留在内部工作层；除非会推翻核心策略或交付承诺，不得把内部审慎语言带入对外提案。

## 前置策略立场门禁

目录生成前，必须明确并记录：

1. 我们替品牌看到了什么确定性机会；
2. 当前真正需要解决的核心矛盾；
3. 我们作出的行业、产品与经营判断；
4. 品牌当前选择为什么正确；
5. 全案主动选择的策略路径；
6. 明确放弃的平庸或无效路径；
7. 希望客户最终作出的决策。

以上问题没有形成清晰答案，不得进入目录、PPT提案成稿与视觉生成。

## 内外双层工作规则

- **内部核验层**：管理事实来源、版本、假设、证据、风险、信息缺口和对抗检查。
- **对外提案层**：呈现机会、矛盾、观点、品牌答案、执行证明、情绪推进与行动。
- 内部核验可以补证、纠错或推翻不成立的判断，不得自动把鲜明观点稀释成“可能、或许、建议关注、待确认”等中性表达。
- 提案创作与事实核验分阶段进行，不允许审计口吻直接生成客户可见文案。

## 逐页说服力合同

每页生成前必须定义：

- `belief_shift`：客户看完后需要发生的认知变化；
- `emotional_target`：需要触发的情绪；
- `decisive_judgment`：本页作出的鲜明判断；
- `visible_proof`：支撑判断的事实、内容原型或执行工作件；
- `next_tension`：引向下一页的问题、期待或未完成动作。

这些字段不必显示在页面上，但必须存在于PPT提案成稿和页面设计意图中；完整讲稿在最终PPT页序锁定后再基于这些字段生成。

## 情绪曲线要求

提案讲稿需像视频脚本一样设计情绪起伏。全案与每个大章节至少包含：

1. 共识建立；
2. 矛盾或机会显现；
3. 压力与期待上升；
4. 策略判断出现；
5. 内容或执行成果完成证明；
6. 向下一章节释放新的期待。

## 四级验收门禁

1. **正确但没有观点：退回。**
2. **有观点但没有证据：补证。**
3. **有观点、有证据，但不能推动客户决策：重写。**
4. **观点、证据、情绪与行动同时成立：通过，方可进入视觉生成。**

补充判定：

> 如果删除品牌名后，一页可以原封不动放进任何行业报告，该页失败。

> 如果一页只做到正确、完整、客观，却没有让客户更想相信、更想继续听或更想选择方案，该页失败。

## 对抗检测要求

逐章确认后的对抗检测，额外检查：

- 观点是否被审慎措辞稀释；
- 每章是否作出了选择；
- 行业信息是否帮助品牌确认自身判断正确；
- 产品事实是否被转化为消费者选择理由；
- 执行内容是否让品牌提前体验到服务成果；
- 标题、PPT成稿和视觉是否共同服务同一情绪曲线；最终讲稿生成后再检查其是否保持同一情绪曲线；
- 审查意见是在纠错，还是把提案重新改成客观报告。
