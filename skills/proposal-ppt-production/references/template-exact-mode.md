# 正式PPTX模板精确跟随模式

当用户提供的PPTX是必须继承的正式模板、现有演示文稿或可编辑母版时，使用本模式。若文件只是审美参考、案例或情绪板，仍执行视觉样张校准，不能误用模板继承。

本模式必须调用本机 Presentations Skill 的 template-following 工作流和工具；本文件只定义提案生产中的治理边界。

## 1. 核心原则

- 检查全部源页面，不只抽样首页和几个内容页。
- 每张输出页必须映射到一个源页面版型。
- 复制源页面并原位修改继承元素，不在模板上覆盖一套平行设计。
- 保留字体、字号、字重、行距、段距、边距、对齐、页脚、页码、母版和品牌Chrome。
- 内容放不下时，先缩短、换版型或拆页，不能静默缩小字体。
- 任何偏离源模板的变化都必须记录原因。

## 2. 必需工作件

- `template-audit.txt`：完整源页面类型、字体、色彩、布局、占位符、品牌元素和可复用范围。
- `template-frame-map.json`：每张输出页对应哪个源页面，以及允许修改的继承元素。
- `deviation-log.txt`：所有有意偏离模板的页面、对象、原因和批准记录。
- `source-notes.txt`：内容、数据和媒体来源。

## 3. 编辑规则

- 默认所有继承对象为保留。
- 只有明确标记为rewrite、replace或delete的对象才能被修改。
- 空结构占位符也必须填充或删除，不能用新文本框覆盖后假装已经处理。
- Logo、页脚、页码、日期、分隔线、章节标识和母版家具不得批量清空。
- 找不到能够承载内容的源页面时，先重新映射；仍无合适版型时向用户报告，不得自行重建一个“相似模板”。

## 4. 数据与媒体

- 数据先计算，再填入继承的图表、表格或指标框。
- 真实人物、产品、界面和证据必须使用可核验资产，不能生成伪截图、伪Logo或近似包装。
- 图片替换后检查裁切、蒙版、尺寸与对齐，不破坏源模板节奏。

## 5. QA

- 比较源页面、starter页面和最终页面的全尺寸渲染。
- 检查字体、换行、裁切、对齐、图表、品牌元素与占位符。
- 检查最终PPTX XML中是否残留空结构占位符。
- 每页独立全尺寸检查；Montage只检查全案节奏。
- 正式交付前使用Presentations Skill的模板一致性检查工具。
