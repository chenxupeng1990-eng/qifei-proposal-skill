# 提案中的数据分析与策略推导规则

本文件定义提案中通用的数据分析、比较与策略推导协议。它不提供任何行业结论或案例答案。所有事实、数值和口径都必须来自当前项目的有效证据；所有分析都必须继续服务后续策略、内容、执行与经营章节。

## 1. 总体分析链路

提案中的分析采用双循环，不假设所有策略都必须由数据从零发现，也不允许先有策略后选择性取数。

### 循环A：策略假设驱动的证据验证

适用于已经存在明确、有力量的产品判断、品牌方向或策略主张时：

`策略假设 → 需要证明的关键命题 → 证据需求 → 支持证据与反证 → 假设校正 → 可辩护的策略结论`

这一循环的目标不是“证明原判断永远正确”，而是判断：

- 哪些证据能够增强策略可信度；
- 哪些条件限定了策略的适用范围；
- 是否存在足以推翻或修改策略的反证；
- 哪些部分属于品牌选择，不能伪装成数据事实。

执行规则：

1. 先把策略写成可被验证或推翻的假设；
2. 明确每个命题需要什么证据，不能先看到数据再改问题；
3. 同时检索支持证据、反向证据和替代解释；
4. 根据证据将假设判定为保留、收窄、调整或放弃；
5. 正式提案只呈现与决策相关的证据链，但内部必须保留反证检查记录。

### 循环B：数据发现驱动的策略推导

适用于策略方向尚不明确，需要从市场、竞争、人群和经营数据中发现机会时：

`数据事实 → 稳定模式 → 关键差距 → 多种解释 → 验证原因 → 机会判断 → 策略选择`

执行规则：

1. 先统一口径并建立事实底表；
2. 从规模、增长、效率、结构和流转中寻找异常与机会；
3. 为同一现象至少保留两个可能解释；
4. 用补充数据或业务信息排除较弱解释；
5. 将剩余结论转化为资源取舍与执行方向；
6. 明确哪些结论是数据直接支持，哪些仍然是策略判断。

### 双循环如何汇合

两条循环最终都必须进入同一个决策门：

`证据是否可靠 → 解释是否唯一或足够强 → 结论是否改变选择 → 策略是否可执行 → 指标是否可验证`

现实项目中，两条循环会反复往返：策略假设决定下一轮需要寻找什么数据，新增证据又会修正策略。允许迭代，不允许循环论证。

每项关键结论必须记录其起点：

| 起点类型 | 必须保留的审查信息 | 合格结果 |
|---|---|---|
| 策略假设驱动 | 原始假设、证据需求、支持证据、反证、修改记录 | 策略得到支持、被收窄或被修正 |
| 数据发现驱动 | 数据口径、异常模式、竞争解释、排除过程、推断边界 | 从事实严谨推到可执行选择 |

无论从哪条循环进入，都不要从“要画什么图”开始，而要从业务问题开始，逐层缩小决策范围：

`市场规模 → 细分增长 → 价格带机会 → 竞争结构 → 品牌差距 → 人群差距 → 触点或产品原因 → 目标与资源缺口`

每一层分别回答一个不同问题：

| 分析层 | 核心问题 | 最少需要的字段 | 应输出的决策 |
|---|---|---|---|
| 市场 | 这个市场是否值得进入或继续投入 | 当前规模、历史规模、增长率、购买人数增长 | 进入／防守／降低优先级 |
| 细分 | 增长集中在哪里 | 品类占比、品类增速、季节性 | 基本盘／增长盘／衰退盘 |
| 价格带 | 哪个商品层级仍有空间 | 各价格带占比与增速 | 入门价、核心价带、升级价带 |
| 竞争 | 谁拿走了增长，以及如何拿走 | 份额、份额变化、GMV增速、渠道结构 | 直接竞品、经营标杆、替代品 |
| 品牌 | 问题出在规模还是效率 | 曝光、点击、购买、转化、ROI | 扩大触达／提升转化／重做供给 |
| 人群 | 哪些是基本盘，哪些是增量 | 规模、占比、TGI、转化、竞品渗透 | 守住核心／获取增量／停止浪费 |
| 触点 | 用户关系在哪一段断裂 | 来源、去向、流转规模、流转率、渠道效率 | 新增、放大、修复或移除触点 |
| 目标 | 执行最终需要补齐多大缺口 | 目标GMV、当前GMV、客单价、UV、转化率、人群资产、成本 | 量化运营要求与投资要求 |

### 1.1 分析链必须连续，不能堆砌独立洞察

每一层分析都必须使用上一层的结论作为输入，并为下一层提供明确约束：

`事实 → 差距 → 原因假设 → 选择标准 → 策略取舍 → 执行动作 → 验证指标`

例如，市场增长不能直接推出“加大内容投入”。中间必须依次回答：

1. 增长具体来自哪个细分、价格带或人群；
2. 品牌是否具备进入该增长区间的产品与信任基础；
3. 当前差距属于认知、供给、触点还是转化；
4. 哪个策略选择可以关闭这项差距；
5. 后续内容、直播、商品、媒介和运营分别承担什么任务；
6. 用什么数据验证策略成立。

如果两个相邻章节之间无法用“因此”连接，说明分析链仍然断裂。

### 1.2 证据强度必须匹配结论强度

根据证据强度控制表达：

| 证据状态 | 可使用的表达 | 不可使用的表达 |
|---|---|---|
| 多来源一致、口径统一、直接支持 | 证明、明确显示、可以判断 | — |
| 单一来源或样本有限 | 提示、支持该判断、初步显示 | 已经证明、必然导致 |
| 相关关系但因果未确认 | 与……一致、可能关联、需要结合业务验证 | 导致、决定、因为 |
| 策略选择或品牌立场 | 我们选择、建议聚焦、应优先 | 数据证明只能这样做 |

“有利证据”必须满足两个条件：确实支持当前策略，并且没有通过隐藏重要反证制造虚假确定性。

### 1.3 每项分析必须生成策略交接单

完成一个分析模块时，必须输出五项内容：

| 字段 | 必须回答的问题 |
|---|---|
| 证据事实 | 数据准确显示了什么 |
| 经营判断 | 这对当前品牌意味着什么 |
| 核心矛盾 | 当前增长最主要的阻力或缺口是什么 |
| 策略选择 | 因此选择什么、放弃什么 |
| 下游任务 | 后续哪些章节必须落实这一选择 |

下游任务至少要映射到以下一项：

- 人群策略；
- 产品与货盘策略；
- 核心创意与内容策略；
- 渠道与触点策略；
- 直播或销售策略；
- 投放与经营策略；
- 目标拆解与复盘指标。

没有下游任务的分析结论，不进入正式提案。

### 1.4 区分事实、推断与策略

- **事实**：由当前证据直接支持；
- **推断**：对事实的解释，必须标明假设条件；
- **策略**：基于事实与推断做出的资源取舍；
- **动作**：策略在具体业务模块中的落地方式；
- **指标**：判断动作是否有效的验证信号。

提案不能把相关性直接写成因果，也不能把策略主张伪装成数据结论。

### 1.5 建立内部证据矩阵

关键策略在进入提案前，应完成内部证据矩阵：

| 策略命题 | 支持证据 | 反向证据／限制条件 | 证据强度 | 当前处理 |
|---|---|---|---|---|
| 要证明什么 | 哪些事实支持 | 哪些事实可能削弱 | 高／中／低 | 保留／收窄／修改／放弃 |

证据矩阵用于控制推理质量，不要求全部展示在客户页面上。正式提案应呈现最短但完整的可信证据链。

## 2. 行业分析方法

### 2.1 规模与增长必须同时出现

不能仅凭增长率就判断一个品类有吸引力。至少同时查看：

- 绝对规模，用于判断生意容量；
- 同比增长，用于判断增长动能；
- 购买人数增长，用于区分“真实扩容”与“价格上涨”；
- 客单价变化，用于判断增长来自消费升级还是更多消费者进入。

推荐载体：

- 柱状图表达规模，折线表达同期增速；
- 横轴为规模、纵轴为增速的散点图；
- 当需要比较多种口径和精确值时，采用紧凑对比表。

标题必须表达结论，例如：

> 高价格带当前占比不高，却贡献了最快的增量增长

### 2.2 从品类继续下钻到价格带

采用两步拆解：

1. 识别基本品类与高增长品类；
2. 在每个品类内部，继续比较各价格带的占比与增速。

将结果归类为：

- **基本盘**：占比大，增速稳定或健康；
- **增长盘**：当前占比较小，但增速明显更高；
- **拥挤盘**：占比大，但增长放缓或已经负增长；
- **伪机会**：基数极小造成的高百分比增长。

如果品类与价格带使用不同分母，必须明确标注，不能直接混合成一个结论。

### 2.3 制定运营日历前先看季节性

月度GMV和增长曲线可以判断一个品类是单峰还是多波段。分析结果不能只停留在趋势图，而要进一步定义：

- 常态经营月份；
- 需求蓄水窗口；
- 核心销售峰值；
- 大促后的恢复期或品类切换期。

## 3. 竞品对比方法

### 3.1 同时比较规模、动能与结构

一张完整的竞品表应包含三层信息：

1. **规模**：GMV或市场份额；
2. **动能**：同比增长与份额变化；
3. **结构**：自营、达人、商品卡、品类或价格带构成。

这可以避免一个常见错误：把最大品牌直接当成最佳经营标杆。规模较小的品牌，可能拥有最快的增速或更值得借鉴的经营结构。

### 3.2 先定义竞品角色，再进行比较

不要使用一组没有差异的竞品名单。应为每个品牌明确角色：

- **直接竞品**：同人群、同品类、同价格带；
- **经营标杆**：漏斗效率或渠道效率更优；
- **增长标杆**：抓住了增长最快的增量市场；
- **替代品**：用另一种定位截取同一消费需求；
- **流量截留者**：承接了最多品牌流失用户。

每个对比对象都必须说明“为什么把它放进来”。

### 3.3 象限只有能导出动作时才有价值

有效的象限组合包括：

- 转化率 × 折扣率；
- 市场份额 × 增长率；
- 人群规模 × 转化效率；
- 触点规模 × 流转效率。

每个象限都必须对应明确动作：放大、优化、维持或停止。无法导出动作的象限，只是装饰性分析。

## 4. 人群分析方法

### 4.1 把人群规模与人群效率拆开判断

对每类人群至少观察：

- 可触达人群规模；
- 品牌曝光或关系人群规模；
- 点击或互动效率；
- 购买转化；
- 竞品渗透率。

由此形成四种诊断：

| 规模 | 效率 | 诊断 | 动作 |
|---|---|---|---|
| 高 | 高 | 核心生意基本盘 | 防守并加深关系 |
| 高 | 低 | 转化或商品供给存在问题 | 修复内容、货盘或直播间 |
| 低 | 高 | 有效率但规模不足的机会 | 扩大媒介和内容供给 |
| 低 | 低 | 匹配度弱 | 降低优先级或重新定义 |

### 4.2 不只看静态画像，还要看人群流转

静态人口属性告诉我们“用户是谁”；流转分析才告诉我们“接下来做什么”。

需要衡量：

- 来源人群 → 去向人群；
- 流转规模与流转率；
- 留存、召回和新获取部分；
- 促成每次流转的触点；
- 同一流转环节的竞品标杆表现。

有效结论示例：

- 兴趣人群规模偏低，是因为缺少高效率内容触点；
- 支付效率健康，但付费流量规模不足；
- 浅层种草人群画像与深度兴趣、交易人群画像不匹配；
- 同一个触点同时承担教育与收割，导致整体效率下降。

### 4.3 用五层递进把画像翻译为经营决策

人群分析不能停在年龄、性别和城市等级，而应依次进入：

1. 人口属性与消费能力；
2. 品类偏好与使用场景；
3. 品牌偏好与核心商品偏好；
4. 内容偏好与媒介偏好；
5. 内容角色、达人角色与商品供给。

这五层递进，决定一份材料是“人群报告”还是“可执行内容策略”。

## 5. 经营数据分析方法

### 5.1 用“规模 × 效率”诊断完整漏斗

对曝光、点击、进入直播间、商品点击和支付，每一层都同时展示：

- 该环节的绝对规模；
- 与上一环节之间的流转效率。

随后定位第一个真正影响结果的主要瓶颈。如果根因是有效流量不足，就不能把低GMV简单归因于转化率。

### 5.2 渠道分析必须同时包含占比、成本与回报

对每个渠道比较：

- 消耗占比或流量占比；
- 千次观看成本、获客成本等流量成本；
- 转化率；
- ROI或GPM；
- 常态经营与大促峰值中的不同角色。

可将渠道归类为：

- 高效率、低规模 → 谨慎增加预算；
- 高规模、低效率 → 修复内容、探索方向或货盘；
- 低成本、低质量 → 仅用于补充流量；
- 节点型渠道 → 保留给首发或Big Day。

### 5.3 将内容指标看作连续信号链

不要把曝光、互动、搜索和成交分别汇报，而要连成：

`曝光 → 互动 → 搜索 → 进入直播间 → 商品点击 → 支付`

典型诊断：

- 高曝光 + 低互动：内容共鸣不足；
- 高互动 + 弱搜索：内容有娱乐性，但没有形成品牌需求；
- 强搜索 + 弱支付：货盘、价格、证据或直播间存在问题；
- 强支付 + 规模不足：有效模型已经形成，等待复制放大。

## 6. 目标拆解与缺口计算

### 6.1 从经营目标反向推导

从目标开始倒算：

`GMV目标 → 订单量 → 所需UV → 所需人群资产 → 投放或内容缺口`

核心公式：

- 订单量 = GMV ÷ 客单价；
- 所需UV = 订单量 ÷ 支付转化率；
- 所需人群资产 = 所需UV ÷ 预计人群资产到访率；
- 投资缺口 = 目标所需资源 − 当前存量 − 预计自然增量。

至少计算三种情景：

- **基准情景**：沿用当前效率；
- **优化情景**：使用明确说明的效率提升假设；
- **风险情景**：采用更低的流量或转化假设。

不能隐藏效率假设。如果转化率提升0.1个百分点就会显著改变投资缺口，应展示敏感性分析。

### 6.2 把目标缺口连接到经营杠杆

每个缺口都必须有责任人与解决杠杆：

| 缺口 | 主要杠杆 | 示例责任方 |
|---|---|---|
| 人群资产缺口 | 内容种草、达人、付费触达 | 内容／媒介 |
| UV缺口 | 素材规模、投放效率、搜索 | 媒介／运营 |
| 转化缺口 | 主播、话术、产品证据、权益 | 直播运营 |
| 客单价缺口 | 组合装、价格梯度、关联销售 | 商品运营 |
| 复购缺口 | 产品体验、会员、再营销 | CRM／品牌 |

## 7. 数据处理规则

### 7.1 先统一口径，再进行比较

每次比较都必须对齐：

- 时间窗口；
- 平台范围与交易定义；
- 品类与价格带分母；
- 付费流量与自然流量；
- 自营与达人贡献；
- 退款前GMV与结算GMV；
- 人群模型定义，尤其是AIPL与5A。

如果口径不同，必须先制作定义映射页，再把数据放在一起使用。

### 7.2 每张分析页输出“事实—意义—动作”

每张分析页应完成三层结论：

1. **事实**：数据字面上显示了什么；
2. **意义**：为什么这件事与品牌有关；
3. **动作**：下一步应该改变什么。

如果数据只证明相关性，不能直接写成因果关系。应使用“提示”“与……一致”“需要进一步验证”等措辞。

### 7.3 保留数据源与计算链路

每个衍生指标都要保留：

- 数据来源系统；
- 提取周期；
- 筛选条件；
- 计算公式；
- 排除项；
- 四舍五入规则；
- 分析者推断。

## 8. 分析页面的最佳视觉载体

| 分析任务 | 推荐载体 | 应避免 |
|---|---|---|
| 市场规模与趋势 | 柱状图 + 增长折线 | 只有一个缺少依据的市场大数字 |
| 品类机会 | 份额 × 增速散点图 | 只按增速排名 |
| 价格带决策 | 品类 × 价格带矩阵 | 混用不同分母 |
| 竞品结构 | 对比表 + 重点行列强调 | 品牌Logo墙 |
| 人群机会 | 规模 × 效率矩阵 | 只有人口属性画像 |
| 人群流转 | 桑基图或来源—去向流转图 | 没有流转率的静态漏斗 |
| 触点诊断 | 规模 × 效率象限 | 触点清单 |
| 目标缺口 | 目标—当前—优化—缺口桥接图 | 只呈现一个目标数字 |
| 年度规划 | 目标拆解表 + 分阶段动作 | 没有量化里程碑的时间轴 |

页面标题必须写成结论，不能只写“市场分析”“人群分析”等栏目名称。

## 9. 分析结论与后续提案的强制映射

数据分析章节结束前，必须建立一张“结论—策略—执行”映射表：

| 分析结论 | 形成的策略选择 | 后续承接章节 | 执行动作 | 验证指标 |
|---|---|---|---|---|
| 市场与增长结论 | 选择进入的细分和增长位置 | 战略定位／产品策略 | 确定核心品类、价格带与阶段目标 | 份额、增速、成交规模 |
| 人群结论 | 定义核心人群与增量人群 | 人群／内容策略 | 分配内容入口、证据顺序和商品承接 | 人群规模、进入率、转化率 |
| 竞品结论 | 选择差异化标准和竞争对象 | 产品价值／核心创意 | 建立新选择标准与对比表达 | 搜索、互动、商品点击 |
| 触点结论 | 确定教育、承接和收割分工 | 内容／直播／渠道策略 | 重组触点任务与内容链路 | 流转率、成本、ROI |
| 商品结论 | 确定主推商品和组合结构 | 货盘／销售策略 | 设计价格梯度、组合与权益 | 客单价、商品点击、支付 |
| 经营结论 | 确定放大条件和资源缺口 | 投放／运营／复盘 | 调整预算、排期、团队与SOP | GMV、GPM、ROI、目标达成率 |

### 9.1 递进审核

提交提案前逐项检查：

1. 每个重要策略是否能追溯到前文的一项分析结论；
2. 每项重要分析是否在后文产生了策略或执行变化；
3. 核心创意是否承接产品、市场和人群共同推导出的价值，而非独立发想；
4. 内容、直播、商品、投放和运营是否服务同一个策略选择；
5. 目标和复盘指标是否验证前文策略，而非只汇报结果；
6. 删除任意一个分析页后，后续决策依据是否会消失；若不会，该页可能是装饰性分析；
7. 删除任意一个策略页后，执行章节是否失去方向；若不会，该策略可能没有真正约束执行。

### 9.2 分析章节的最终产出

分析章节最终不是输出“我们知道了什么”，而是输出：

> 基于哪些事实，我们选择在哪个增长位置，以什么人群和产品价值建立差异，并通过哪些触点与经营动作实现目标

这句话必须能够成为后续整份提案的逻辑主线。
