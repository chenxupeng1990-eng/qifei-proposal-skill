# 祈飞提案生成层视觉 Demo｜提案策划书

## 背景与任务

- 背景：虚构熟龄营养项目，仅用于隔离验证提案生成链路。
- 目标：验证冻结内容、品牌视觉依据、Image2 与 HTML 统一排版，以及多格式导出。
- 评审对象：内部工具链验收人员。
- 成功标准：五页视觉一致，无越界，可从 HTML 导出 PNG、PDF 和图片型 PPT。

## 范围与边界

- 范围内：内容契约、视觉审计、HTML 母版、Codex 浏览器原生评论和导出。
- 范围外：真实客户策略、报价、经营承诺和正式品牌资产。
- 核心限制：不得读取、改写或影射任何真实客户项目内容。

- Q1：是否使用真实客户内容？推荐不使用；决定采用虚构熟龄营养项目。

- Q3：PPT 是否要求可编辑？推荐本轮只验证预览；决定输出图片型 PPT。
