# 校准样张 ↔ 正式生产要求对照

对照依据：`references/page-production-loop.md`（底图＋文字层、文字区、参考图规则）与 `design-and-generation.md` 第 7 条（产品与 Logo）。样张上的文字只取母稿 `PPT上屏内容`。

| 样张类型 | 整页底图 | 文字区与组件 | 参考图与产品 | 只有上屏内容 | 结论 |
|---|---|---|---|---|---|
| cover | 铺满整页，主体为品牌场景 | 标题组落在左侧暗部 | 无产品 | 是 | 可作母版 |
| toc | 克制底图，保留章节编号区 | 编号列表 | 无产品 | 是 | 可作母版 |
| chapter-type-led | 大字章节标记压在留白区 | 章节标记 | 无产品 | 是 | 可作母版 |
| chapter-image-led | 场景主导，文字区为虚化前景 | 标题组＋信息带 | 无产品 | 是 | 可作母版 |
| chapter-data-led | 底图克制，数据由 HTML 承担 | 数据行 | 无产品 | 是 | 可作母版 |
| content-low | 整页场景，文字少 | 标题组 | 无产品 | 是 | 可作母版 |
| content-medium | 整页场景，右侧干净区 | 标题组＋编号列表 | 无产品 | 是 | 可作母版 |
| content-high | 底图更克制，卡片承接文字 | 卡片＋来源 | 无产品 | 是 | 可作母版 |
| content-visual-module | 底图之上叠透明 PNG 模块 | 卡片 | 透明 PNG 为补充，不替代底图 | 是 | 可作母版 |
| closing | 整页场景收尾 | 标题组 | 无产品 | 是 | 可作母版 |
